# @pine/wayspot-core

The Wayspot export format, the S2 cells and the geometry that Professor Pine and the Pine Wayspot export tool share: an npm workspace of Pine, one subpath per module (`@pine/wayspot-core/s2`). Its conventions are in Pine's `docs/architecture/wayfarer.md`; its fixtures are the contracts with the tool (`fixtures/README.md`).

MIT (`LICENSE`), unlike the rest of Pine (GPL-3.0), so that the private export tool may bundle it. The notice goes with every copy, the tool's bundle included.
